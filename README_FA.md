# راهنمای اپلیکیشن آموزش آلمانی با داستان 🇩🇪

این پروژه دقیقا برای کسی که کدنویس نیست طراحی شده.

### تو اصلا لازم نیست کد بزنی!

منطق اپ اینطوریه:
- تمام کدهای اپلیکیشن در پوشه `lib/` از قبل نوشته شده.
- تو فقط باید فایل‌های JSON درس‌ها را در پوشه `assets/lessons/` اضافه کنی.
- هر درس = یک فایل JSON مثل `a1_l01.json` که من قالبش را بهت می‌دهم.

### مسیر ساده و درست برای خروجی گرفتن:

#### ۱. مرحله خروجی کروم (که بلدی)
در VS Code ترمینال را باز کن:
```
flutter pub get
flutter run -d chrome
```
اپ در مرورگر باز می‌شود و می‌توانی تست کنی.

#### ۲. مرحله خروجی اندروید (نیازی به اندروید استودیو برای تبدیل کروم به اپ نیست!)
وقتی از کروم راضی بودی، فقط همین یک دستور را بزن:
```
flutter build apk --release
```
بعد از 2-3 دقیقه فایل APK در مسیر زیر ساخته می‌شود:
`build/app/outputs/flutter-apk/app-release.apk`
همین فایل را مستقیم می‌توانی روی گوشی نصب کنی یا در گوگل پلی بذاری.

### آیا راه آسان‌تر از فلاتر هم هست؟

بله، اگر حتی فلاتر هم برات سخت است، ۲ راه دیگر داری:

**راه A (پیشنهاد من): همین پروژه فلاتر را ادامه بده**
چون من تمام کد را برایت می‌نویسم. این بهترین و حرفه‌ای‌ترین راه است و در آینده می‌توانی به راحتی بخش اشتراک پولی و ... اضافه کنی.

**راه B (بدون کد - فوق سریع): استفاده از FlutterFlow**
1. به سایت flutterflow.io برو
2. یک پروژه جدید بساز (drag & drop - مثل پاورپوینت)
3. فایل‌های JSON که من بهت می‌دهم را به عنوان Data بهش بده
4. خودش با یک کلیک APK بهت می‌دهد.
هزینه: ماهانه حدود 30 دلار، ولی اصلا کد نمی‌خواهی.

**راه C (فقط وب اپ):**
من می‌توانم به جای فلاتر، یک نسخه وب ساده (HTML) هم بهت بدهم که با سایت هایی مثل `PWABuilder.com` در 2 دقیقه تبدیل به اپلیکیشن اندروید می‌شود.
